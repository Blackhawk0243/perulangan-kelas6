Keajaiban Mesin Pengulang! 🔁

Kenapa programmer bisa bersantai minum es jeruk sambil komputernya bekerja jutaan kali? Rahasianya ada di Perulangan (Loop).

Mulai Petualangan! 🚀
🤔

1. Kenapa Kita Butuh Perulangan?

Bayangkan kamu disuruh menggambar 5 bintang di layar komputer. Tanpa perulangan, kamu harus menulis kode yang sangat membosankan seperti ini:

❌ Tanpa Loop (Bikin Capek)

gambarBintang();
gambarBintang();
gambarBintang();
gambarBintang();
gambarBintang();
// Bayangkan kalau disuruh 1000 bintang! 😭

✅ Dengan Loop (Sangat Cerdas)

ulangi 5 kali {
    gambarBintang();
}
// Mau 1000 bintang? Tinggal ganti angkanya! 😎

💡 Kesimpulan: Loop membuat kode lebih singkat, pintar, dan menghemat tenaga programmer!

2. Anatomi Perulangan 🦴

Setiap mesin pengulang yang baik HARUS punya 3 tombol rahasia ini. Kalau kurang satu saja, komputernya bisa bingung!

🚦

1. Titik Awal

(Start / Inisialisasi)
Dari angka berapa kita mulai menghitung? Ibarat garis start di arena balap.

🛑

2. Syarat Berhenti

(Kondisi / Condition)
Sampai kapan loop ini bekerja? Komputer akan terus bekerja SELAMA syarat ini bernilai BENAR.

👣

3. Langkah

(Step / Iterasi)
Setiap kali selesai 1 tugas, apa yang terjadi? Apakah hitungan bertambah (maju) atau berkurang (mundur)?

3 Tipe Mesin Loop ⚙️

1

🏃‍♂️ FOR Loop (Si Paling Pasti)

Gunakan saat kamu SUDAH TAHU PASTI berapa kali tugas harus diulang.

Contoh 1: Hitung Maju

Robot mengantar 3 kotak barang berurutan.

for (let i = 1; i <= 3; i++) {
    antarBarang(i);
}

Contoh 2: Hitung Mundur

Peluncuran roket luar angkasa (Mundur dari 3 ke 1).

for (let i = 3; i >= 1; i--) {
    cetak("Detik " + i);
}
cetak("Meluncur!");

🎮 Playground FOR Loop

Tekan tombol di bawah untuk menjalankan loop hitung mundur roket!

2

⚔️ WHILE Loop (Si Pengecek Syarat)

Gunakan saat kamu BELUM TAHU jumlah perulangannya, tapi kamu tahu SYARAT BERHENTINYA. (Syarat dicek di awal).

Contoh 1: Nyawa Monster

Serang monster SELAMA nyawanya (HP) lebih dari 0.

let hpMonster = 100;

while (hpMonster > 0) {
    serangDenganPedang();
    hpMonster -= 20; // Nyawa berkurang
}

Contoh 2: Makan Sampai Kenyang

Makan bakso selama perut belum kenyang.

let kenyang = false;

while (kenyang == false) {
    makanSatuBakso();
    kenyang = cekPerut(); // Update syarat
}

🎮 Playground WHILE Loop

Serang monster! Selama HP > 0, While loop akan terus mengizinkanmu menyerang.

👾

HP: 100/100

3

🕹️ DO-WHILE (Lakukan Dulu!)

Mirip WHILE, tapi bedanya: Pekerjaan PASTI dilakukan MINIMAL 1 KALI, karena syaratnya dicek di akhir.

Contoh 1: Password Pintu

Suruh masukkan password dulu (DO). Jika salah, suruh ulang (WHILE).

let passwordBenar = false;

do {
    ketikPassword();
} while (passwordBenar == false);

Contoh 2: Mesin Capit

Main dulu. Setelah koin masuk, kalau koin masih ada, boleh main lagi.

let koin = 2;

do {
    mainCapitBoneka();
    koin--; // Koin berkurang
} while (koin > 0);

🎮 Playground DO-WHILE

Kotak Misteri! Coba buka kotak ini. Walaupun energi (syarat) kamu 0, Do-While mengizinkanmu mencoba MINIMAL 1 kali.

📦

Energi Kamu: 0

🚨

Awas: Infinite Loop! (Bencana Programmer)

Apa yang terjadi jika kamu disuruh berlari, tapi tidak ada garis finish-nya? Kamu akan pingsan kelelahan!

Begitu juga komputer. Jika kamu lupa membuat Syarat Berhenti yang bisa bernilai SALAH (False) atau lupa menulis Langkah (Step), komputer akan terjebak mengulang tugas tanpa henti. Akibatnya? Program akan hang atau macet total!
